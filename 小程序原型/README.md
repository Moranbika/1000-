# 1000天营养起航 —— 小程序原型（知识指导版）

本目录归档了项目已构建的**可交互网页应用原型**（原型/知识指导版，内置演示数据，无需后端与数据存储）。

## 原型概况

| 项目 | 内容 |
|---|---|
| 应用名称 | 1000天营养起航——孕期营养与婴幼儿喂养小程序 |
| 版本定位 | 原型 / 知识指导版（demo 数据，无真实用户数据） |
| 技术栈 | Vite + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui |
| 交互特性 | 移动端优先（max-w-lg 单列卡片流），暖杏橙主色 + 米白纸感背景 |
| 当前状态 | 已部署预览版（妙搭平台托管），完整可运行代码在构建沙箱中可随时再次导出 |

## 已实现功能模块

1. **首页 / 阶段引导**：Hero 主视觉 + 1000天时间轴进度 + 8个阶段卡片网格 + 当前阶段营养重点速览
2. **分阶段营养指导**：备孕期、孕早/中/晚期、哺乳期、0-6月龄、6-12月龄、12-24月龄共 8 个阶段，每阶段含核心营养原则、重点营养素（含食物来源）、膳食建议、注意事项、一日参考食谱、警惕信号六大模块（手风琴展开 + 阶段间快速切换）
3. **营养工具（4个）**：孕期体重增长建议（BMI→增重范围）、宝宝奶量估算、辅食月龄对照、关键营养素查询（6营养素×7人群阶段）
4. **每日小贴士 / 健康打卡**：当日营养贴士 + 打卡动效 + 连续天数 + 7天历史
5. **营养知识库**：7个分类 Tab + 搜索 + 文章详情页（含相关推荐与免责声明）
6. **FAQ 常见问题**：母乳喂养、辅食过敏、营养素补充、孕期禁忌等

## 本地运行方式

```bash
# 1. 安装依赖
npm install
# 2. 启动开发服务器
npm run dev
# 3. 构建生产版本
npm run build
# 4. 类型检查
npm run typecheck
```

## 注意事项

- 代码中使用的 3 张 AI 配图（Hero 主视觉、营养食物插画、宝宝喂养场景）托管在平台静态资源服务上；本地部署时需替换为自有图片，放入 `public/` 或 `src/assets/` 并修改页面中图片 URL。
- `src/components/ui/` 下 57 个 shadcn/ui 组件为标准组件，可用 `npx shadcn@latest init` + `npx shadcn@latest add <component>` 重新生成。
- 所有数据均为内置演示数据（mock）。

## 源码导出

完整源码导出内容见同目录 `原型源码导出.md`。如需某文件的完整原始代码（如 `src/data/stages.ts` 全量569行、`src/data/nutrients.ts` 全量358行等），可在对话中要求从构建平台重新导出后补入本目录。
